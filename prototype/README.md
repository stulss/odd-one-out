# 프로토타입 — 단계별 데모 (Day 1 ~ Day 6)

## ⚠ 먼저 밝힐 것

**이 파일들은 "그날 실제로 존재했던 코드"가 아닙니다.**
Day 2~6은 한 번에 개발되었고, 이후 "각 단계에서 무엇이 늘어나는지"를 보여주기 위해
**되짚어 재구성한 데모**입니다. 과정 증거로 제출하실 경우 이 사실을 함께 밝혀 주세요.

실제 개발 순서의 기록은 `../작업내역_체크리스트.md`의 **작업 로그**에 있습니다.
(Day 1만 실제로 그 시점에 단독으로 만들어진 코드입니다.)

## 각 단계에서 늘어난 것

| 단계 | 추가된 것 | 그 단계에서 답한 질문 |
|---|---|---|
| **day1** | 격자 · 다른 하나 · 선택 판정 | 이거 재미있나? |
| **day2** | 시드 난수 · 제한 시간 · 점수 · 게임오버 · 다시 하기 | "한 판"이 성립하나? |
| **day3** | 화면 4개 · 컬러 · 규칙 상시 표시 · 일시정지 · 해상도 대응 | 처음 보는 사람이 규칙을 알 수 있나? |
| **day4** | 차이 축 10종 · 도형 4종 · 키보드 조작 · 공정성 검증 | 10판 해도 지겹지 않나? |
| **day5** | localStorage · 오늘의 문제 · 결과 카드 · 공유 · 소리/움직임 토글 | 친구에게 보낼 이유가 있나? |
| **day6** | 자동 일시정지 · 손상 복구 · 플레이 로거 · 난이도 T 슬라이더 | 오래 켜둬도 안 망가지나? |

→ 그다음이 본 빌드(`../index.html` + `../src/`)입니다. day6의 코드를 13개 모듈로 분리한 것입니다.

## 실행

day1~day6은 **모듈을 쓰지 않는 단일 파일**이라 브라우저로 바로 열어도 됩니다.
(본 빌드만 ES 모듈이라 서버가 필요합니다)
