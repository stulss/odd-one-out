# 딱 하나 이상함

여러 개 중 딱 하나 다른 것을 제한 시간 안에 찾는 브라우저 관찰력 게임.
React + TypeScript(Vite)로 만들었고, 이미지 파일·음원 파일 없이
SVG·CSS와 Web Audio API·Canvas만으로 화면과 소리를 그립니다.

> 과제 "내가 설계한 미니게임" 제출용 프로젝트입니다.
>
> **▶ 플레이: https://odd-one-out-nine.vercel.app/**

## 규칙

플레이어는 **화면의 격자 칸**을 조작해
**여럿 중 딱 하나 다른 칸을 찾아 선택하면** 성공하고,
**제한 시간이 0이 되면** 실패한다.

| 조작 | 키 |
|---|---|
| 선택 | 클릭 · 터치 · <kbd>Enter</kbd> |
| 이동 | <kbd>←</kbd> <kbd>↓</kbd> <kbd>↑</kbd> <kbd>→</kbd> |
| 일시정지 | <kbd>P</kbd> · <kbd>Esc</kbd> |

| 판정 | 조건 | 결과 |
|---|---|---|
| **정답** | 다른 하나를 제한 시간 안에 선택 | 다음 단계, 점수 +（격자 크기 × 속도 × 콤보) |
| **오답** | 같은 칸을 선택 | **남은 시간 −1초**, 콤보 초기화 (즉사 아님) |
| **시간 초과** | 제한 시간이 0 | 종료, 정답 위치 공개 |

## 차이의 종류

난이도는 **칸 수가 아니라 차이의 미묘함**으로 올라갑니다.
칸 수는 4×6=24칸이 상한이고, 그 이유는 360px 기기에서도 최소 터치 크기 44px를 지키기 위해서입니다.

| 축 | 무엇이 다른가 | 축 | 무엇이 다른가 |
|---|---|---|---|
| 색조 | 색이 조금 돌아감 | 위치 | 살짝 밀려 있음 |
| 밝기 | 조금 밝음 | 기울기 | 살짝 기울어짐 |
| 크기 | 조금 큼 | 채도 | 색이 조금 빠짐 |
| 회전 | 살짝 돌아감 | 윤곽선 | 테두리 두께가 다름 |
| 선명도 | 살짝 번져 보임 | 투명도 | 조금 연함 |

각 축에는 **지각 임계값**이 정의되어 있어, 후반에도 "아무도 못 찾는 판"이 나오지 않습니다.
칸은 '복제품' 8종(버섯·열쇠·주전자·물고기·우산·유령·약병·책)이며 한 단계의 모든 칸은 같은 물건입니다. SVG 경로(`engine/objects.ts`)로 그려서 화면과 결과 카드가 같은 데이터를 씁니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 검사 + 배포용 빌드 → dist/
npm run preview    # 빌드 결과 확인
npm test           # 순수 로직 단위 테스트 (vitest)
```

배포는 Vercel이 `vercel.json`에 따라 `npm run build` → `dist/`를 서빙합니다.

**구조 원칙** — 게임 규칙·타이머·저장은 `engine/`에 두고 React는 화면만 맡습니다.
매 프레임 바뀌는 시간 게이지와 파티클은 React 상태를 거치지 않고 직접 갱신해 리렌더를 만들지 않습니다.

**단계별 실제 구현 기록** → [`prototype/`](prototype/STEPS.md)
`step1`~`step6`을 한 단계씩 실제로 만들고 검증한 순서가 그대로 남아 있습니다.

## 모드 · 접근성 · 설치

- **감별 사건부(메인 모드)**: 6개 구역 × 사건 3개 = 18개 사건. 사건마다 5라운드(구역의 마지막 사건은 7라운드)를 시간 안에 풀면 해결이고, 오답과 속도로 별 1~3개를 받습니다. 사건은 앞 사건을 해결해야 열립니다. 코드는 `engine/campaign.ts`(규칙·데이터), `components/CaseScreens.tsx`(지도·결과·도감).
- **성장·수집**: 해결하면 🪙코인을 받고, 구역 마지막 사건을 해결하면 새 복장(마법사·닌자·사제·유랑민·도적)이 해금됩니다. 코인으로 소품·옷색·💡힌트(정답 칸을 잠깐 비춤)를 삽니다. 찾아낸 물건 8종은 도감에 기록되고 10·50·200번째에 보상이 있습니다. 캐릭터의 진화 단계는 사건 진행도와 무한 모드 기록 중 높은 쪽을 따릅니다.
- **그 밖의 모드**: 일반(무한) / 30초 도전(전체 30초 안에 몇 단계) / 연습(시간 제한 없음, 차이 축 선택, 기록 없음). 도전장·오늘의 문제는 항상 일반 모드입니다.
- **업적 10종**: 설정 시트에서 확인합니다.
- **접근성**: 색 구분 보조(색조·채도 차이를 밝기 차이로 표시, 문제 자체는 동일), 고대비, 스크린리더 안내(`aria-live`).
- **세계관·캐릭터**: 이상 감별국의 신입 감별사가 되어 5단계마다 구역(수습 훈련실 → 복제 공장 → 거울 미로 → …)을 지나며 안내 로봇 '렌즈'의 이야기를 듣습니다. 복장 6종(탐정·마법사·닌자·사제·유랑민·도적)과 머리색·피부·옷색·소품을 직접 고르고, 등급이 오르면 복장 위에 망토·견장·오라·날개·후광이 한 겹씩 얹힙니다. 전부 코드로 그린 SVG입니다(`Hero.tsx`, `story.ts`, `StoryScreen.tsx`).
- **연출**: 정답 파티클·콤보 단계별 효과·오답 화면 흔들림·판 3D 등장·구역별 배경색 전환(`fx.ts`, `theme.css`). 공정성을 위해 게임판에는 상시 기울이기/그림자를 걸지 않습니다. '움직임 줄이기'를 켜면 모든 연출이 꺼집니다.
- **PWA**: 서비스 워커·매니페스트를 빌드 때 자동 생성합니다(오프라인 실행·홈 화면 설치). 새 버전은 자동으로 교체되므로 버전을 손으로 올릴 필요가 없습니다.
- **공유 미리보기**: `public/og-image.png`(1200×630). 아이콘·OG는 `python tools/make_icons.py`로 다시 만듭니다.

## 특징

- **런타임 의존성은 React뿐** — 웹폰트·이미지·음원·CDN은 쓰지 않습니다. 빌드 결과 JS는 약 87KB(gzip)입니다.
- **이미지 파일 0개** — 게임 오브젝트를 전부 CSS로 그립니다. 차이를 1px·3° 단위로 **정확히 제어**해야 난이도 곡선이 성립하는데, 래스터 이미지는 축소 과정에서 차이가 뭉개져 불공정한 실패를 만듭니다.
- **음원 파일 0개** — 효과음을 Web Audio API 오실레이터로 합성합니다.
- **같은 링크 = 같은 문제** — 시드 난수로 구현해 서버 없이 '오늘의 문제'와 '도전장'이 성립합니다. 날짜는 KST 고정이라 해외에서 열어도 같은 문제입니다.
- **끊기지 않는 루프** — rAF 루프가 앱 전체에 1개뿐이고, 게이지·파티클은 리렌더 없이 갱신합니다. 칸은 안정적인 key로 재사용됩니다.
- **저장값을 못 믿는 설계** — 현재 판의 값은 **아예 저장하지 않습니다.** 저장하면 초기화 코드를 따로 만들어야 하고 반드시 빠뜨리는 항목이 생깁니다. 저장값이 깨져 있어도(빈값/문자열/누락/타입오류/배열) 기본값으로 실행됩니다.
- **선택권** — 음소거와 움직임 줄이기를 화면에서 즉시 켜고 끌 수 있습니다. 움직임 줄이기는 효과를 없애는 대신 색 점멸로 대체해, 사건 인지 자체는 유지합니다.
